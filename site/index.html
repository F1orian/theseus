The rooms

A calm app for serious work.

Room I · Chat

Answers that arrive as they're written.

Responses stream in token by token, with Markdown, code blocks, math and tables. When a model thinks, searches the web or calls a tool, each step appears in the answer and opens with a tap. Sources are listed underneath.

  • Edit a message, retry a response, and move between branches
  • Copy, share, read aloud, rate or report any answer
  • Follow-up suggestions under each answer

Room II · Models

Every model on your server, one tap away.

The model picker lists every model your server offers, with what each one can do: see images, read files, search the web, run code. For models that support it, choose how much effort they spend, from a quick reply to a long, careful one.

  • A default model, and a different one for any chat
  • Effort levels, from low to max
  • Web search, code execution, Skills and Connectors, switched per chat

Room III · Artifacts & code

Ask for a thing. Get the thing.

Artifacts (HTML pages, SVG and diagrams) open in a sandboxed viewer with a live preview and the code, and they work offline. If your server has a sandbox, models run Python there and hand back charts and files you can open or share.

  • Live preview and source, side by side
  • Python in Open Terminal or a Jupyter code interpreter
  • Charts and generated files, right in the chat

Room IV · Projects, memory & history

Everything in its place.

The drawer holds all your chats, with search, stars and recents. Projects group chats with their own instructions and knowledge files, each under a cover from the collection. Memory shows what the server remembers about you, and you can edit or delete any of it.

  • Projects with instructions and knowledge
  • Memory, custom instructions and styles
  • Search across every chat on the server

Room V · Voice

Talk it through.

Dictate into the composer, or switch to voice mode and talk hands-free: it listens, answers aloud and shows the conversation as text. Speech is recognised and spoken on the device by default.

Room VI · iPad

More room on iPad.

A sidebar that stays open, split view, and keyboard shortcuts for everything you do often.

After hours · Incognito & privacy

No one else in the building.

Theseus has no servers of its own and collects nothing. Your chats go only to the server you connect to, and through it to the AI providers its admin set up. Incognito chats aren't saved at all, not even to your history or memory.

  • No analytics, no ads, no tracking, no third-party SDKs
  • Your sign-in token lives in the iOS Keychain
  • Speech is recognised on the device by default

At the information desk

Before you install.

Do I need my own server?

Yes. Theseus is a client for Open WebUI 0.12 or newer. It doesn't host any models and doesn't come with an account. You, your team or your organisation run the server; the models are whatever its admin connected, from local ones to cloud providers.

How do I sign in?

With the account you already have on the server: a password, LDAP, or your organisation's single sign-on, with two-step verification. Theseus doesn't create accounts; your server's admin does. Several servers and accounts can sit side by side.

Where do my chats go?

Only to your server, and through it to the AI providers its admin set up. Theseus keeps a copy on your device so it opens fast and works offline, and you can delete it in Settings › Data & privacy. Nothing goes to us: we don't run a server for Theseus.

Can it run code?

If your server has a sandbox, yes: Open Terminal or a Jupyter code interpreter. Models run Python there and send back charts and files.

Which devices does it run on?

iPhone and iPad with iOS 26 or iPadOS 26 or later. The server needs to be reachable over HTTPS, or on your local network.

Is it open source?

Yes. Theseus is GPL-3.0, and the code is on GitHub. Issues and pull requests are welcome.

Is Theseus made by Open WebUI?

No. Theseus is an independent app and isn't affiliated with the Open WebUI project. Questions about your account or the models go to your server's admin; questions about the app go to theseus@unru.sh.
